# 1ПМ Калькулятор

PWA для расчёта одноповторного максимума по формулам Эпли и Брзицки. История тренировок и графики. Без бэкенда, всё хранится в localStorage браузера.

```
Epley:   1RM = W * (1 + R / 30)
Brzycki: 1RM = W * 36 / (37 - R)
```

Обе формулы валидны в диапазоне 1-10 повторений. При 10 и более повторениях показывается предупреждение о снижении точности, при 37 и более расчёт блокируется: у Брзицки знаменатель уходит в ноль.

## Что умеет

- Регистрация одним экраном при первом запуске: имя, аватар, пол, антропометрия
- Расчёт 1ПМ по двум формулам, 20 упражнений по группам мышц плюс свои
- Рабочие веса на 1-12 повторений по таблице NSCA (Baechle, Earle. Essentials of Strength Training and Conditioning)
- Разминочная лесенка к рабочему весу и раскладка блинов на штангу
- Дыхательные практики: квадрат 4-4-4-4, схема 4-7-8, когерентное дыхание 5.5
- История, личные рекорды и прогресс за 30 дней
- Очки DOTS по сумме троеборья с поправкой на собственный вес

Аватар ужимается до квадрата 192px и лежит в localStorage вместе с профилем: наружу ничего не уходит.

## Команды

```bash
npm run dev      # разработка, http://localhost:5173
npm run test     # юнит-тесты (формулы, хранилище, рендер экранов)
npm run build    # проверка типов + продакшен-сборка в dist/
npm run preview  # локальный просмотр собранной версии с рабочим service worker
```

Иконки пересобираются из `public/icon-source.svg`:

```bash
npm run generate-icons
```

## Проверка PWA

Service worker работает только в собранной версии, не в `npm run dev`.

1. `npm run build`, затем `npm run preview`
2. DevTools → Application → Service Workers: статус `activated and running`
3. DevTools → Application → Manifest: иконки и `theme_color` без ошибок, блок Installability пустой
4. DevTools → Network → Offline, перезагрузить страницу: приложение должно открыться и работать

## Публикация на GitHub одной командой

```bash
powershell -ExecutionPolicy Bypass -File setup-github.ps1
```

Скрипт создаёт git-репозиторий, коммит, репозиторий на GitHub через `gh`, заливает код и включает
GitHub Pages со сборкой из Actions. Если `gh` не установлен, он подскажет команду установки и покажет
ручные шаги. Существующий `origin` скрипт не трогает — только пушит.

После пуша workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml) прогоняет тесты,
собирает проект и публикует на `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Базовый путь берётся из переменной `BASE_PATH`: Pages отдаёт сайт из подпапки, поэтому workflow
подставляет `/имя-репозитория/`, а локальная сборка и Netlify работают из корня без настройки.

## Деплой на Netlify

`netlify.toml` уже настроен (`npm run build`, публикация `dist`, SPA-редирект).

1. Инициализировать git-репозиторий и запушить его на GitHub
2. Netlify → Add new site → Import an existing project → выбрать репозиторий
3. Настройки сборки подхватятся из `netlify.toml`, менять ничего не нужно

После деплоя открыть сайт на телефоне и добавить на главный экран: приложение запустится в standalone-режиме, без адресной строки.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/lib/formulas.ts` | Формулы 1ПМ и валидация числа повторений |
| `src/lib/storage.ts` | Профиль, история, свои упражнения, экспорт/импорт JSON |
| `src/lib/breathing.ts` | Схемы дыхания и раскладка фаз по времени |
| `src/screens/` | Регистрация, профиль, расчёт, дыхание, прогресс |
| `src/components/charts/` | Графики на чистом SVG, без библиотек |
| `src/hooks/useCountUp.ts` | Анимация числа результата |

Данные профиля (возраст, рост, вес) в расчёте 1ПМ не участвуют: хранятся отдельным ключом для будущих доработок.
